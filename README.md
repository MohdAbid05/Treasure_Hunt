How to run from a shell window:

Open console (terminal, command.exe, whatever)

Navigate to inside treasure_hunt folder : 
Either navigate to folder using terminal instruction 

cd "Absolute path"
eg: cd "C:\Users\Lenovo\OneDrive\Desktop\treasure_hunt" for windows/linux
or 
open the folder in your file explorer/manager, right click and choose open in terminal option

Compile the code:(ensure you have jdk installed, check using java -version/javac -version   )

javac *.java

Run the code:

java Driver

Don't forget, if you edit the code then recompile it before running.
